# Книги для проверки

Положите сюда любые книги (TXT, FB2, FB2.ZIP, EPUB, PDF, HTML) и запустите тесты:

    uv run pytest

Каждая книга из этой папки (и из `data/`) будет открыта и проверена: что нашлись главы, у глав есть названия
и текст, нет слишком длинных глав и остатков разметки. Сами книги в git не попадают.
